## Replace the track

1. Put a new MP3 in this folder. Use only your own music or a track whose licence
   allows commercial website use, and keep the licence proof.
2. In `index.html`, find `ZS_MUSIC` (in `<script id="zs-music-script">`) and change
   `src` (and `title`).
3. To turn the player off, set `src: ''`. The player then shows "Music coming soon".
